## Exercices script bash
Le script à la fin sur la dernière diapo du cours sur bash semble demander à l'utilisateur un fichier à analyser. Le script crée une variable "OK" qui va servir de compteur pour le nombre de lignes dans le fichier ressemblant à une URL valide. Il crée également une variable "NOK" qui, elle, va servir de compteur pour les lignes ne ressemblant pas à une URL.
Le script ouvre ensuite le fichier en lecture dans une boucle while et va retourner pour chaque ligne du fichier, le numéro de ligne et si elle ressemble à une URL valide en ajoutant à chaque tour + 1 soit dans "OK", soit dans "NOK". Une fois que le script a parcouru tout le fichier, il retourne un string disant combien d'URLS valides et de lignes ne correspondant pas à des URLS ont été trouvées.
